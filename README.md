# 🎮 Online Gaming Behavior Analysis

This is a Streamlit web application that analyzes player engagement, demographics, and in-game behavior. 

## Overview
This dashboard visualizes an online gaming dataset to explore:
* Distribution of player engagement levels.
* Popularity of various game genres.
* Correlations between play time, age, and in-game purchases.
